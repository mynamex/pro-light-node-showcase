# Contributing

Thank you for your interest in contributing to Pro-Light Node.

This project focuses on embedded BLE Mesh infrastructure, production-oriented architecture, and scalable lighting communication systems.

## Development Principles

* Stability over shortcuts
* Real hardware validation
* Production-oriented architecture
* Clear subsystem responsibilities
* Maintainable protocol design

## Before Contributing

Please:

* Open an issue first for major architectural changes
* Keep commits focused and readable
* Test changes on real hardware whenever possible
* Include logs/screenshots when reporting mesh-related issues

## Areas of Interest

Contributions are especially welcome in:

* BLE Mesh reliability
* Embedded architecture
* ESP-IDF optimization
* Diagnostics and telemetry
* Synchronization systems
* Documentation improvements
