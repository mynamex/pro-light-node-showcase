# Security Policy

This repository is currently under active development and experimental architecture iteration.

If you discover security-related issues or unsafe runtime behaviors, please open an issue with detailed reproduction steps and hardware/runtime information.

The project focuses heavily on:

* runtime safety
* embedded stability
* production-oriented mesh infrastructure
* reproducible diagnostics


## Responsible Disclosure

If you discover a security-related issue, protocol vulnerability, or unsafe mesh behavior, please open a private security report instead of creating a public issue.
